trong direction: turn it into a personal conversation intelligence assistant
That is a much more compelling product idea than a generic note-taker. The value becomes clearer:

help you understand people better in real conversations
remember key details about friends, strangers, clients, or colleagues
suggest better follow-up questions and conversation topics
turn meetings into deeper relationship understanding rather than just task extraction
Core product idea
A personal assistant that can:

listen to or ingest a conversation
extract themes, interests, emotions, personality signals, and relationship cues
build a personal profile for each person
suggest follow-up actions, conversation starters, and reminders
help you remember what matters about that person over time
Best positioning
Frame it as:

“Personal relationship intelligence assistant”
“Conversation understanding companion”
“Social memory assistant for better human connections”
This feels more human and useful than “AI productivity app.”

Key features for the MVP
Conversation analysis
summary of the discussion
main topics discussed
emotional tone
key interests and motivations
possible hidden concerns or needs
Person profile memory
store notes per person
remember preferences, recurring topics, personal context
track relationship strength and follow-up history
Follow-up suggestions
smart questions to ask next time
topics to revisit
reminders to check in later
Privacy-first design
only analyze with consent
local-first storage where possible
clear controls for deleting memories
How this changes your current app
Your current app is already close to the foundation. The main shift is:

replace task extraction as the main output
make “person understanding” the main output
So instead of only extracting tasks, the AI should extract:

people mentioned
what they care about
what they are struggling with
what they value
what would make the next conversation more meaningful
Suggested architecture change
You can evolve the current flow like this:

Voice/text input
Transcript processing
Person and relationship analysis
Profile memory storage
Follow-up suggestions and reminders
Important caution
This should be built ethically. Avoid making it feel invasive or manipulative. The best version is:

helpful
consent-based
respectful
private
Recommended next step
The best MVP would be:

a “Analyze conversation” feature
a “People profiles” section
one short insight output:
who this person is
what they care about
what to ask next
That would make the product feel useful immediately.
